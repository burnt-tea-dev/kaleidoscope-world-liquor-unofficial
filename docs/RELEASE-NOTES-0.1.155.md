# World Liquor 0.1.155

Deferred furniture interactions now retain the hand and target accepted by the original event. Switching slot, changing the item/count/observable metadata or potion identity, changing dimension or crouch state, or replacing/changing the target block cancels the queued action before it can consume another item. The freezer's Adventure allowance and native complete-item storage remain intact. The same guard covers the existing jukebox, wall-record and painting routes.

The freezer blue-dye display previously used the exact lapis-lazuli sprite. It now uses the original Minecraft 1.21.1 blue-dye PNG, reconstructed through a pinned official-source generator. The existing alpha-tested plane reads the corrected outline.
