# World Liquor 0.1.170

Adopt NeoForge1.1.12 / Forge1.1.13 pendant lamps, dye recipes, cabinet models/textures, Dassai custom Luck+, Explosion power, underwater CaptainGift exclusion and air-jump velocity. Submerged-eye detection includes native waterlogged blocks. Requires BDS1.26.60, @minecraft/server2.12.0-beta, Beta APIs and Upcoming Creator Features.

The complete 47-pack family passed BDS1.26.60.6 first load and restart on a copy of the latest consistently stopped survival save, followed by LIVE installation and exact file/order readback. Eight player records remained unchanged in both copy runs. The shared [deployment observation](https://github.com/burnt-tea-dev/kaleidoscope-tavern-unofficial/blob/8cb52ddedf7d03e261f5c5cf3950e358623cd760/docs/evidence/family-deployment-20261028.json) owns the source identities, receipt hashes, warnings and evidence limits.

Luck currently rerolls emitted native mob-death loot and adds previously absent item types while cloning the native ItemStack. Mining, chest, fishing and global Java loot contexts, plus TreasureSense outlines, remain open. The [current source review](https://github.com/burnt-tea-dev/kaleidoscope-world-liquor-unofficial/blob/ba123792914035200dc1a43400cb6d1cd36fa567/data/current-author-review-20261028.json) and [isolated native evidence](https://github.com/burnt-tea-dev/kaleidoscope-world-liquor-unofficial/blob/ba123792914035200dc1a43400cb6d1cd36fa567/docs/evidence/current-java-content-20261028.json) distinguish adopted behavior from remaining gaps. The native fixture verified lore and quantities; it did not exhaust every possible item component.

Real-client rendering, audio, creative categories, C04 inventory stacks and normal-play performance remain unverified. This release keeps client acceptance pending and production_ready=false; it does not mark the full S1 plan complete.
